Help test a full voyage

Start with normal play, then try to break the interactions. Tick a box only after its expected behavior passes. Leave failures unticked and record the test number in your notes. Checks and notes save in this browser on this address.

Difficulty scales enemy health, damage, speed and shields throughout the voyage, including elites and later waves. Hard has 4 / 4 / 5 / 5 / 6 / 6 combat rounds across the six encounters; Standard gets one extra round and Relaxed two. The clock advances with combat actions, never animation duration or real-world waiting. Gold, starter crew rules, enemy counts and rewards stay the same. These are tuning presets, not balanced final modes. Choose a preset, then use Start new test voyage to apply it. Open game resumes the current run without changing its settings.

Economy and feel

Begin with Standard at 70 integrity, then compare Relaxed and Hard at the same starting integrity. Only then try lower integrity. Crew and packs are random, so repeat each setting and record the starting crew; a single comparison is noisy.

For each encounter, note: difficulty, integrity before/after, crew, field level, gold before shopping, packs bought, upgrade cost, gold at launch, win/loss, and reward. Also record “I wanted to buy ___ but couldn't,” dull stretches, confusing effects, and animations that were too fast to follow. Those are useful findings even when nothing crashes.

Base victory gold for encounters 1–6 is 34 / 40 / 46 / 52 / 58 / 64; qualifying Survey Prism rewards can add a bonus. A defeat pays 10. One successful run is not proof that every starter team is balanced.

Already known — don't spend your first run retesting these
  • Active battles still do not resume the same action after reload. Test interruptions separately from a clean full voyage.
  • Integrity does not currently end the voyage at zero. It affects recovery and final grading.
  • Calls, persistent cross-voyage catalogue unlocks and combat audio remain unfinished. The Ops Calls placeholder is replaced by the working voyage-goal control.
  • Some crew still share prototype combat kits. Descriptions now reflect the current kits; this does not mean every lore character has a unique finished kit.
  • Homeworld assignments, recipes, prices and modifier values are proposals for testing. They are not a final balance sign-off.
  • First offline battle navigation has a known routing bug. This HTTP test is for online gameplay; PWA/offline checks need a separate HTTPS build.
