# Portrait style board

These images are the approved visual references for Spacology portrait artwork.

- `stella.png` — soft character rendering, paper grain, graphic elemental disc
- `ilka.png` — character framing, field gear, restrained linework
- `feline-major.png` — animal-forward anatomy treatment
- `ojo.png` — non-human material anatomy and distinctive silhouette
- `bird-folk.png` — feather treatment and element-led palette
- `enemy.png` — enemy profile treatment and exposed anatomical abstraction

Use the board for rendering language only. Character complexion, hair, facial structure,
species anatomy, age, clothing, and element color come from each character brief.
