# Texture sources

All sets are from [ambientCG](https://ambientcg.com) and are CC0 1.0 (public domain); no attribution is required, it is given here for traceability.
Each folder holds the 1K-JPG Color, NormalGL and Roughness maps, recompressed (JPEG q82). `textures.js` stylises them at load:
the colour map is turned into a neutral, softly banded detail map (the kit's vertex colours supply the hue), and roughness is
floored so surfaces stay matte under cel shading.
